# Gordon Price — CS 499 ePortfolio

A simple, responsive portfolio homepage for GitHub Pages.

Intended repository: `GPricedeveloping/GPricedeveloping.github.io`

Intended website: https://gpricedeveloping.github.io/

## Sections

- Professional Self-Assessment
- Code Review
- Software Engineering & Design
- Algorithms & Data Structures
- Databases

Coursework sections are clearly marked as coming soon. Replace the placeholders
with the actual self-assessment, code review, artifacts, and enhancement narratives.
The starter page is not a completed capstone submission.

## Publishing

Place `index.html` in the root of the repository. In GitHub repository Settings >
Pages, select Deploy from a branch, then `main` and `/ (root)`, and save.
No external fonts, libraries, tracking, build tools, or custom domain are required.
